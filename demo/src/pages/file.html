التثبيت

إضافة لا جزء من الملفّين: ملفّ أنماط وملفّ سكربت يُحمَّلان بعد المكتبة.

منطقة الإفلات

حقل ملفّات عاديّ عليه data-ins-file. تُسحب الملفّات إليه أو تُختار أو تُلصق، وتظهر تحته: صورة مصغّرة للصور، ونوع الملفّ لغيرها، والاسم والحجم وزرّ الإزالة.

ملفّات PDF أو صور.

الملفّات تبقى في الحقل الحقيقيّ: كلّ تغيير يُكتب في files الحقل نفسه، فيرسلها النموذج كما هي. والحقل باقٍ في ترتيب التنقّل تحت تسميته، للوحة المفاتيح وقارئ الشاشة.

الحدود

  • accept — كما يقرؤه المنتقي، ويُطبَّق على الإفلات واللصق أيضًا، وهما لا يمرّان به.
  • data-ins-file-max — أكبر حجم للملفّ: 500KB، 5MB.
  • data-ins-file-count — أكبر عدد للملفّات، مع multiple.

ملفّ خارج الحدود لا يُضاف، ويقول الحقل أيّ ملفّ ولماذا. ومع multiple يُضاف الاختيار الجديد إلى القائمة، وبدونه يستبدلها. والسطر الصغير في المنطقة يُكتب من الحدود، أو من data-ins-file-note.

المضغوط

لنموذج ضيّق: class="ins-file--compact" على الحقل، زرّ وقائمة بلا منطقة. والإفلات على الزرّ يعمل.

الرفع الفوريّ

مع data-ins-file-upload يطلق كلّ ملفّ يُضاف ins:file، فترفعه الصفحة وتبلّغ الإضافة بما جرى. عندها يرسل الحقل بدل الملفّات حقلًا مخفيًا باسمه لكلّ رفع تمّ، يحمل المعرّف الذي أعطته الصفحة، ويبقى غير صالح ما دام ملفّ في الطريق أو تعذّر رفعه. الرفع هنا مصطنع، وملفّ في اسمه «خطأ» يتعذّر عمدًا:

document.addEventListener('ins:file', async (e) => { if (!e.detail.upload) return; const file = e.detail.file; try { const id = await send(file, (fraction) => Insiyab.file.progress(file, fraction)); Insiyab.file.done(file, id); // حقل مخفيّ باسم الحقل يحمل المعرّف } catch (err) { Insiyab.file.fail(file, 'تعذّر الرفع، أزِل الملفّ أو أعد إضافته.'); } }); Insiyab.file('#docs'); // الملفّات في القائمة Insiyab.file('#docs', []); // أفرغها
