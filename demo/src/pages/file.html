التثبيت

إضافة مستقلة عن المكتبة: ملف أنماط وملف سكربت تضعهما بعد ملفاتها.

منطقة السحب والإفلات

ضع data-ins-file على حقل ملفات عادي، فتسحب الملفات إليه أو تختارها أو تلصقها، وتظهر تحته في قائمة: للصورة نسخة مصغرة ولغيرها نوعه، ومع كل ملف اسمه وحجمه وزر لإزالته.

ملفات PDF أو صور.

تبقى الملفات في الحقل الحقيقي: فكل تغيير يُكتب في files الحقل نفسه، ويرسلها النموذج كما هي. ويبقى الحقل بتسميته في ترتيب التنقل بمفتاح Tab، فتصل إليه لوحة المفاتيح ويفهمه قارئ الشاشة.

الحدود

  • accept — يفهمه الحقل كما يفهمه منتقي الملفات، ويطبقه على الإفلات واللصق أيضًا مع أنهما لا يمران بالمنتقي.
  • data-ins-file-max — أكبر حجم للملف، مثل 500KB أو 5MB.
  • data-ins-file-count — أكبر عدد للملفات، ويعمل مع multiple.

والملف الذي يتجاوز الحدود لا يُضاف، ويذكر الحقل اسمه وسبب رفضه. ومع multiple ينضم ما تختاره إلى القائمة، ومن دونها يحل محلها. أما السطر الصغير في المنطقة فيكتبه الحقل من الحدود، إلا أن تكتبه أنت في data-ins-file-note.

الشكل المضغوط

وإذا ضاق النموذج فضع class="ins-file--compact" على الحقل، فيصير زرًا وقائمة بلا منطقة إفلات، ويبقى الإفلات على الزر ممكنًا.

الرفع الفوري

مع data-ins-file-upload يُطلق كل ملف تضيفه حدث ins:file، فترفعه الصفحة ثم تخبر الإضافة بما جرى. وحينئذ يرسل الحقل مكان الملفات حقلًا مخفيًا باسمه عن كل ملف رُفع، يحمل المعرف الذي أعطته الصفحة. ويبقى الحقل غير صالح ما دام ملف قيد الرفع أو تعذر رفعه. والرفع في هذا المثال مصطنع، وكل ملف في اسمه «خطأ» يتعذر رفعه عمدًا:

document.addEventListener('ins:file', async (e) => { if (!e.detail.upload) return; const file = e.detail.file; try { const id = await send(file, (fraction) => Insiyab.file.progress(file, fraction)); Insiyab.file.done(file, id); // حقل مخفي باسم الحقل يحمل المعرف } catch (err) { Insiyab.file.fail(file, 'تعذر الرفع، أزِل الملف أو أعد إضافته.'); } }); Insiyab.file('#docs'); // الملفات في القائمة Insiyab.file('#docs', []); // أفرغها
