ثلاث حالات لا اثنتان

فاتح وداكن اختياران صريحان يُحفظان ويُختمان بسمة data-ins-theme على <html>. والنظام يزيل السمة فيتبع إعداد نظام التشغيل. جرّب:

من الشيفرة

Insiyab.theme(); // 'light' | 'dark' — ما يراه المستخدم فعلًا، أيًّا كان مصدره Insiyab.theme('dark'); // اختيار صريح، يُحفظ Insiyab.theme('system'); // ينسى الاختيار ويتبع النظام من جديد Insiyab.toggleTheme(); document.addEventListener('ins:theme', (e) => { console.log(e.detail.theme, e.detail.mode); // 'dark', 'dark' | 'system' });

مصمَّم، لا مقلوب

الداكن لوحة ثانية بقيمها الخاصة، لا فلتر فوق الأولى:

  • حافة الزجاج أخفت، وتشبّع الضباب أقلّ.
  • الظلال أغمق، والتلوينات الدلالية أقوى لتبقى مرئية.
  • الدرجة المقروءة من لون الهوية تتّجه نحو الأبيض لا نحو الأسود.

قبل أوّل رسم

الاختيار المحفوظ يُستعاد لحظة قراءة السكربت في <head>، فضعه هناك دون defer وإلّا ومضت الصفحة بالفاتح ثمّ انقلبت.

في أنماطك أنت

اقرأ المتغيّرات فتتبع الوضع وحدها. وإن احتجت قاعدة للداكن، فاكتبها للحالتين: الاختيار الصريح، والنظام حين لا اختيار.

/* الأفضل: متغيّر يتبع الوضع بنفسه */ .my-card { background: var(--ins-surface); color: var(--ins-text-1); } /* وحين يلزم فعلًا */ :root[data-ins-theme="dark"] .my-chart { filter: brightness(.9); } @media (prefers-color-scheme: dark) { :root:not([data-ins-theme="light"]) .my-chart { filter: brightness(.9); } }
