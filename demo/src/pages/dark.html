الفاتح والداكن واتباع النظام

الفاتح والداكن اختياران صريحان، يُحفظ كل منهما ويثبت بسمة data-ins-theme على <html>. أما النظام فيزيل السمة، فتتبع الصفحة إعداد نظام التشغيل. جرب بنفسك:

من الشيفرة

Insiyab.theme(); // 'light' | 'dark' — ما يراه المستخدم فعلًا، أيًا كان مصدره Insiyab.theme('dark'); // اختيار صريح، يُحفظ Insiyab.theme('system'); // ينسى الاختيار ويتبع النظام من جديد Insiyab.toggleTheme(); document.addEventListener('ins:theme', (e) => { console.log(e.detail.theme, e.detail.mode); // 'dark', 'dark' | 'system' });

ألوان خاصة بالوضع الداكن

للوضع الداكن لوحة ألوان مستقلة بقيمها، وليست ألوان الفاتح مقلوبة بـ filter:

  • حافة الزجاج أخفت، والألوان خلفه أقل تشبعًا (saturate).
  • الظلال أعمق، وألوان النبرات أقوى حتى تبقى ظاهرة.
  • تميل الدرجة المقروءة من لون الهوية إلى الأبيض بدل الأسود.

قبل أن تظهر الصفحة

يستعاد الاختيار المحفوظ لحظة يقرأ المتصفح insiyab-boot.js في <head>، فأبقه هناك دون defer، وإلا ومضت الصفحة بالفاتح ثم انقلبت.

في أنماطك

استعمل المتغيرات في أنماطك، فتتبع الوضع من تلقاء نفسها. وإن احتجت قاعدة خاصة بالداكن فاكتبها للحالتين: حين يختاره المستخدم صراحة، وحين يتبع النظام ولم يختر شيئًا.

/* الأفضل: متغير يتبع الوضع بنفسه */ .my-card { background: var(--ins-surface); color: var(--ins-text-1); } /* وحين يلزم فعلًا */ :root[data-ins-theme="dark"] .my-chart { filter: brightness(.9); } @media (prefers-color-scheme: dark) { :root:not([data-ins-theme="light"]) .my-chart { filter: brightness(.9); } }
