ثلاث حالات لا اثنتان

فاتح وداكن اختياران صريحان يُحفظان. والنظام لا يحفظ شيئًا ولا يختم شيئًا، فيبقى إعداد نظام التشغيل هو الحاكم — ولهذا غياب السمة له معنى. جرّب:

من الشيفرة

Insiyab.theme(); // 'light' | 'dark' — ما يراه المستخدم فعلًا، أيًّا كان مصدره Insiyab.theme('dark'); // اختيار صريح، يُحفظ Insiyab.theme('system'); // ينسى الاختيار ويتبع النظام من جديد Insiyab.toggleTheme(); document.addEventListener('ins:theme', (e) => { console.log(e.detail.theme, e.detail.mode); // 'dark', 'dark' | 'system' });

مصمَّم، لا مقلوب

قلب زجاج أبيض شفّاف يعطي ألواحًا رمادية حليبية بحواف بيضاء صارخة. الداكن هنا لوحة صُمّمت لذاتها:

  • الحافة تنزل من ٨٥٪ إلى ١٠٪ — حافة بيضاء ساطعة على سطح داكن تبدو إطارًا لا ضوءًا.
  • التشبّع في الضباب ينزل من ١٤٠٪ إلى ١٢٠٪، لأنّ الألوان خلف سطح داكن تصرخ بسرعة.
  • الظلال أغمق وأقوى معًا، والتلوينات الدلالية تتضاعف تقريبًا لتبقى مرئية.
  • الدرجة المقروءة من لون الهوية تنقلب اتجاهها: نحو الأبيض لا نحو الأسود.

قبل أوّل رسم

الاختيار المحفوظ يُستعاد لحظة قراءة السكربت في <head>، قبل أن يُرسم أيّ شيء. هذا هو السبب الوحيد لكون السكربت متزامنًا في الرأس: بدونه تومض كلّ صفحة بالفاتح ثمّ تنقلب.

في أنماطك أنت

الأفضل أن تقرأ المتغيّرات، فتتبع الوضع دون قاعدة واحدة إضافية. وإن احتجت قاعدة للداكن فعلًا، فاكتبها للحالتين: الاختيار الصريح، والنظام حين لا اختيار.

/* الأفضل: متغيّر يتبع الوضع بنفسه */ .my-card { background: var(--ins-surface); color: var(--ins-text-1); } /* وحين يلزم فعلًا */ :root[data-ins-theme="dark"] .my-chart { filter: brightness(.9); } @media (prefers-color-scheme: dark) { :root:not([data-ins-theme="light"]) .my-chart { filter: brightness(.9); } }
