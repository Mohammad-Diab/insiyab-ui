التثبيت

إضافة مستقلة عن المكتبة: ملف أنماط وملف سكربت تضعهما بعد ملفاتها.

حقل الرمز

يكفيك حقل واحد تضع عليه data-ins-otp بعدد الخانات، فتظهر تحت الأرقام نقطة لكل خانة تمتلئ بلون الهوية كلما كتبت رقمًا، فيعرف صاحب الرمز كم بقي عليه. والرمز الصحيح في هذا المثال 123456، وما سواه مرفوض:

رمز من ستة أرقام.

يبقى حقلًا واحدًا: فالأرقام ونقاطها مرسومة فوق حقل نصي حقيقي، ولذا يعمل معه اقتراح الهاتف للرمز ولصقه ومدير كلمات المرور وقارئ الشاشة كما تعمل مع أي حقل. وإن غاب السكربت بقي ذلك الحقل على حاله.

لا يرى قارئ الشاشة إلا حقلًا نصيًا واحدًا باسمه وتلميحه، فالأرقام والنقاط المرسومة مخفية عنه. وتسمية الحقل عليك، بـ <label> أو aria-label.

جرّب الحقل

اختر من الخيارات، فيتغير الحقل وشيفرته معًا. وتجد الخيارات كلها بشرحها في آخر الصفحة.

الكتابة

  • في الخانة التالية دائمًا — أينما نقرت في الحقل وقع المؤشر بعد آخر رقم، ويحذف Backspace آخر رقم.
  • الأرقام العربية — تصير ١٢٣٤٥٦ في الحقل 123456.
  • اللصق — لا يأخذ الحقل إلا الرمز، فإذا لصقت «رمزك هو ١٢٣ ٤٥٦» امتلأ بـ 123456.
  • الرمز الناقص — يبقى الحقل غير صالح برسالة «اكتب الرمز كاملًا» حتى تمتلئ خاناته، أما الحقل الفارغ فأمره إلى required.

التحكم بـ JavaScript

document.addEventListener('ins:otp', async (e) => { // اكتمل الرمز const ok = await verify(e.detail.value); if (!ok) { e.detail.input.setAttribute('aria-invalid', 'true'); // يحمر الحقل، ويعود مع الكتابة Insiyab.otp(e.detail.input, ''); // وافرغ الحقل لمحاولة جديدة } }); Insiyab.otp('#code'); // الرمز المكتوب Insiyab.otp('#code', '123456'); // ضبطه بهدوء، دون حدث
