التثبيت

إضافة لا جزء من الملفّين: ملفّ أنماط وملفّ سكربت يُحمَّلان بعد المكتبة.

حقل الرمز

حقل واحد عليه data-ins-otp وعدد الخانات. الرمز الصحيح هنا 123456، وأيّ رمز آخر يُرفض:

رمز من ستّة أرقام.

يبقى حقلًا واحدًا: المربّعات مرسومة فوق حقل نصّيّ حقيقيّ، فاقتراح الهاتف للرمز ولصقه ومدير كلمات المرور وقارئ الشاشة تعمل كما في أيّ حقل. وبلا سكربت هو ذلك الحقل نفسه.

الكتابة

  • في الخانة التالية دائمًا — النقر على أيّ مربّع يضع المؤشّر بعد آخر رقم، وBackspace يحذف الأخير.
  • الأرقام العربية — ١٢٣٤٥٦ تُقرأ 123456.
  • اللصق — يبقى الرمز وحده: «رمزك هو ١٢٣ ٤٥٦» تملأ 123456.
  • ناقص — الحقل غير صالح برسالة «أدخل الرمز كاملًا» حتّى تمتلئ الخانات، والفارغ يتولّاه required.

العدد والحروف والإرسال

من ٤ إلى ١٠ خانات، وdata-ins-otp-chars="alnum" لرمز بحروف لاتينية وأرقام، تُكتب كبيرة. وdata-ins-otp-submit يرسل النموذج حين تمتلئ آخر خانة:

من الشيفرة

document.addEventListener('ins:otp', async (e) => { // اكتمل الرمز const ok = await verify(e.detail.value); if (!ok) { e.detail.input.setAttribute('aria-invalid', 'true'); // المربّعات حمراء، وتعود مع الكتابة Insiyab.otp(e.detail.input, ''); // وافرغ الحقل لمحاولة جديدة } }); Insiyab.otp('#code'); // الرمز المكتوب Insiyab.otp('#code', '123456'); // ضبطه بهدوء، دون حدث

السمات

السمةما تفعله
data-ins-otp="6"يجعل الحقل حقل رمز بهذا العدد من الخانات (٤–١٠). بلا قيمة: maxlength، وإلّا ستّة.
data-ins-otp-chars="alnum"حروف وأرقام بدل الأرقام وحدها.
data-ins-otp-submitيرسل النموذج حين يكتمل الرمز.
aria-invalid="true"رمز رفضه الخادم: المربّعات حمراء حتّى يُكتب من جديد.

لقارئ الشاشة حقل نصّيّ واحد باسمه وتلميحه، والمربّعات مخفيّة عنه. وتسمية الحقل عليك: <label> أو aria-label.
