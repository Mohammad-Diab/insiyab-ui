التثبيت

إضافة لا جزء من الملفّين: ملفّ أنماط وملفّ سكربت يُحمَّلان بعد المكتبة.

شجرة ملفّات

قوائم متداخلة عليها data-ins-tree. أوّل عنصر في كلّ بند تسميته — span أو رابط، وفيها أيقونة إن شئت — والقائمة داخله فرعه، مغلق إلّا مع data-open. وعدد أو شارة بعد التسمية يذهب إلى آخر الصفّ. وبلا سكربت هي القائمة المتداخلة نفسها.

لوحة المفاتيح

الشجرة محطّة واحدة في ترتيب التنقّل، والأسهم تمشي فيها كما في شجرة ملفّات:

  • ↑ ↓ بين الصفوف الظاهرة، وHome End إلى أوّلها وآخرها.
  • السهم نحو الداخل — ← في العربية و→ في الإنجليزية — يفتح الفرع، ثمّ يدخله.
  • السهم نحو الخارج يغلق الفرع، أو يخرج إلى الأب.
  • * يفتح كلّ الفروع بجانب البند، وحرف ينتقل إلى أوّل صفّ يبدأ به.
  • Enter يتبع الرابط أو يختار، وSpace يختار — أو يضع العلامة في شجرة مربّعات.

شجرة صلاحيات

data-ins-tree-checks وتسمية كلّ بند مربّع .ins-check: الفرع يعلّم كلّ ما فيه، وفرع علامته جزئية يظهر مختلطًا ولا يُرسَل مع النموذج.

من الشيفرة

document.addEventListener('ins:tree', (e) => { console.log(e.detail.action, e.detail.label, e.detail.item); // select · open · close · check }); Insiyab.tree('#node-42', 'select'); // يختاره ويفتح الطريق إليه Insiyab.tree('#files', 'open'); // يفتح كلّ الفروع، أو 'close' Insiyab.tree('#files'); // البند المختار — أو المعلَّمة في شجرة مربّعات
