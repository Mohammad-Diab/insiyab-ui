الحوار

<dialog class="ins-dialog"> فيه .ins-dialog-head و.ins-dialog-body و.ins-dialog-foot. زرّ فيه data-ins-dialog يفتحه، وdata-ins-dialog-close داخله يغلقه. التركيز محبوس فيه، وEsc يغلقه ويعيد التركيز إلى الزرّ الذي فتحه. والنقر خارجه لا يغلقه، كي لا تضيع نقرة شاردة ما كُتب فيه.

نصّ الحوار.

المقاسات

--sm لسؤال قصير، و--lg لمحتوى عريض كجدول.

نصّ قصير.

محتوى عريض.

التأكيد

data-ins-confirm على زرّ أو رابط أو نموذج يسأل قبل أن يمضي الإجراء، وdata-ins-confirm-ok نصّ زرّ التأكيد. والزرّ المصمَّم خطرًا يحصل على زرّ تأكيد أحمر تلقائيًا. ومن الجافاسكربت، Insiyab.confirm() يعيد وعدًا بـ true أو false.

const yes = await Insiyab.confirm('أرشفة العنصر؟', { title: 'تأكيد', confirm: 'أرشفة' }); if (yes) archive();

Insiyab.dialog('#dlg', 'open'); Insiyab.dialog('#dlg', 'close'); Insiyab.dialog('#dlg'); // تبديل
