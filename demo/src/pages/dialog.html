مربع الحوار

يتألف مربع الحوار <dialog class="ins-dialog"> من رأس .ins-dialog-head ومتن .ins-dialog-body وذيل .ins-dialog-foot. يفتحه زر يحمل data-ins-dialog، ويغلقه من داخله زر يحمل data-ins-dialog-close. وما دام مفتوحًا بقي التركيز محبوسًا فيه، ويغلقه مفتاح Esc ويعيد التركيز إلى الزر الذي فتحه. أما النقر خارجه فلا يغلقه، حتى لا تذهب نقرة شاردة بما كتبته فيه.

عنوان الحوار

نص الحوار.

المقاسات

يناسب --sm سؤالًا قصيرًا، ويتسع --lg لمحتوى عريض مثل جدول.

حوار صغير

نص قصير.

حوار كبير

محتوى عريض.

التأكيد

ضع data-ins-confirm على زر أو رابط أو نموذج، فيسأل المستخدم قبل أن يمضي الإجراء، واكتب في data-ins-confirm-ok نص زر التأكيد. وإذا كان الزر من أزرار الخطر جاء زر التأكيد أحمر تلقائيًا. ومن جافاسكربت تعيد Insiyab.confirm() كائن Promise ينتهي إلى true أو false.

const yes = await Insiyab.confirm('أرشفة العنصر؟', { title: 'تأكيد', confirm: 'أرشفة' }); if (yes) archive();
