مربع الحوار

يفتح <dialog class="ins-dialog"> زرٌ يحمل data-ins-dialog، ويبقى التركيز محبوسًا فيه حتى يُغلق. أما النقر خارجه فلا يغلقه، حتى لا تذهب نقرة شاردة بما كتبته فيه. وتجد الخيارات كلها بشرحها في آخر الصفحة.

وأزرار الذيل على قاعدة واحدة في المكتبة كلها، في الحوار والدرج والتأكيد والنوافذ المنبثقة: تصطف في نهاية السطر، والزر الرئيسي آخرها وقبله زر الإلغاء، وما لا يُنهي الحوار، كالحذف أو «اليوم»، يقف وحده في أوله. وعلى الهاتف تتقاسم الأزرار العرض بارتفاع يناسب الإصبع.

وإذا فتحت حوارًا من حوار، أو قائمة داخله، أظلمت الصفحة مرة واحدة وبقي الأول خلف الثاني. ويغلق Esc والنقر خارجه أعلاهما وحده، ثم يعود التركيز إلى الزر الذي فتحه، ولا تتمرر الصفحة خلفهما ما داما مفتوحين.

التأكيد

ضع data-ins-confirm على زر أو رابط أو نموذج، فيسأل المستخدم قبل أن يمضي الإجراء. وإذا كان الزر من أزرار الخطر جاء زر التأكيد أحمر تلقائيًا.

ومن جافاسكربت تعيد Insiyab.confirm() كائن Promise ينتهي إلى true أو false.

const yes = await Insiyab.confirm('أرشفة العنصر؟', { title: 'تأكيد', confirm: 'أرشفة' }); if (yes) archive();

التحكم بـ JavaScript

Insiyab.dialog('#dlg', 'open'); Insiyab.dialog('#dlg', 'close'); Insiyab.dialog('#dlg'); // تبديل

الخيارات

كل ما في مربع الحوار والتأكيد من كلاسات وسمات، لكل منهما صندوق يفتح بالنقر.
