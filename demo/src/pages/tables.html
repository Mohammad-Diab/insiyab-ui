الجدول

ضع .ins-table داخل .ins-table-wrap، فإذا ضاق الغلاف عن الجدول تمرر أفقيًا وبقيت الصفحة على عرضها. واختر من الخيارات، فيتغير الجدول وشيفرته معًا، وتجدها كلها بشرحها في آخر الصفحة.

تثبيت رأس الجدول وعموده الأول

للجدول الطويل أو العريض: يبقى رأسه أو عموده الأول ظاهرًا وهو يتمرر داخل غلافه.

الترتيب

إذا وضعت data-ins-sort على رأس عمود صار زرًا يرتب الصفوف تصاعديًا ثم تنازليًا. وترتب الأرقام بقيمها والنصوص بحسب لغة الصفحة، ويرتب Insiyab.sort(th) من الشيفرة.

ويُطلق حدث ins:sort قبل الترتيب، فإذا كان الترتيب على الخادم فألغه، ليتحرك السهم وحده وتجلب أنت الصفوف مرتبة.

document.addEventListener('ins:sort', (e) => { e.preventDefault(); // الخادم يرتب load({ column: e.detail.column, dir: e.detail.dir }); });

تحديد الصفوف

عمود من المربعات يحدد الصفوف، وشريط يعرض عدد المحدد منها وما يمكن فعله بها. وتعيد لك Insiyab.selection('#people') الصفوف المحددة.

التعديل في مكانه

خلية تصير حقلًا إذا نقرتها، فيعدل المستخدم القيمة دون أن يغادر الجدول.

ويُطلق حدث ins:edit قبل حفظ التغيير، فألغه إن أردت رفض القيمة، أو احفظها على الخادم واستدع revert() إذا فشل الحفظ.

document.addEventListener('ins:edit', async (e) => { const ok = await save(e.detail.row, e.detail.value); if (!ok) e.detail.revert(); // تعود القيمة القديمة });
