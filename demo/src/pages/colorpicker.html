التثبيت

إضافة لا جزء من الملفّين: ملفّ أنماط وملفّ سكربت يُحمَّلان بعد المكتبة.

حقل اللون

حقل اللون الأصليّ عليه data-ins-color، في مجموعة حقل. يصير حقل رمز سداسيّ وأمامه عيّنة تفتح المنتقي، ويرسل #rrggbb باسمه كما يرسله حقل المتصفّح:

التباين

في أسفل المنتقي اللون نصًّا على الأبيض وعلى الأسود، ونسبة التباين (Insiyab.color.contrast)، وهل تبلغ 4.5:1 الذي يحتاجه نصّ الفقرات.

المنتقي

  • المربّع للتشبّع والسطوع، بالسحب أو بلوحة المفاتيح: ← → للتشبّع و↑ ↓ للسطوع، ومع Shift بخطوات من عشرة.
  • شريط الدرجة — حقل مدى أصليّ، بلوحة المفاتيح كما هو.
  • ألوان جاهزة — لون الهوية ولوحة حوله، أو ما يقوله data-ins-color-swatches، وnone يخفيها.
  • القطّارة تلتقط لونًا من الشاشة، حيث يوفّرها المتصفّح.
  • الكتابة — #abc أو abc أو aabbcc، ويُكتب كاملًا عند مغادرة الحقل. وما ليس لونًا يُرفض برسالة.

من الشيفرة

document.addEventListener('ins:color', (e) => { Insiyab.brand(e.detail.value); // لوّن الصفحة كلّها باللون المختار }); Insiyab.colorField('#brand'); // اللون Insiyab.colorField('#brand', '#0f766e'); // ضبطه بهدوء، دون حدث

input في أثناء حركة اللون، وchange وins:color حين يُضبط. الحقل الأوّل أعلاه موصول بـ Insiyab.brand() هكذا.
