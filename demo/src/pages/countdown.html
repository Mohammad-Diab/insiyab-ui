العدّ التنازلي

.ins-countdown مع data-ins-countdown يعدّ الوقت الباقي كلّ ثانية. الرقم ثوانٍ من فتح الصفحة، وغيره لحظة الانتهاء: 2026-09-26T18:00:00+03:00. يصفرّ حين يبقى data-ins-warn ثانية (دقيقة إن لم يُذكر) ويحمرّ عند الصفر، ويُطلق ins:countdown في الحالتين.

--lg لعدّ هو موضوع الصفحة.

document.addEventListener('ins:countdown', (e) => { if (e.detail.state === 'end') release(e.detail.el); // أو 'warn' }); Insiyab.countdown('#hold', 600); // من جديد

حالة الحفظ

.ins-save يقول هل حُفظ آخر تغيير: جارٍ الحفظ، ثم حُفظ، أو تعذّر. الحالة في data-ins-state، وبلا حالة يحفظ مكانه ولا يُظهر شيئًا فلا يقفز السطر حين يظهر.

حفظ تلقائي

data-ins-autosave على نموذج: بعد لحظة من آخر تغيير يقول المؤشّر «جارٍ الحفظ» ويُطلق ins:autosave ببيانات النموذج. ألغِه واحفظ على الخادم ثم استدعِ done(true) أو done(false)؛ وإن لم تلغِه فقد حُفظ التغيير عندك، مسوّدة محلّية مثلًا، ويقول المؤشّر ذلك فورًا.

document.addEventListener('ins:autosave', async (e) => { e.preventDefault(); const ok = await fetch('/draft', { method: 'POST', body: e.detail.data }).then((r) => r.ok); e.detail.done(ok); });
