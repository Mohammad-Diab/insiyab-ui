العد التنازلي

ضع data-ins-countdown على .ins-countdown فيعد الوقت الباقي ثانية بعد ثانية، ويتلون بالأصفر حين يقترب الصفر ثم بالأحمر عنده. اختر من الخيارات فيتغير العداد وشيفرته معًا، وتجد الخيارات كلها بشرحها في آخر الصفحة.

التحكم بـ JavaScript

الأوامر نفسها من جافاسكربت، والحدث الذي تستمع إليه.

Insiyab.countdown('#timer', 'start'); // يبدأ، أو يكمل من حيث توقف Insiyab.countdown('#timer', 'stop'); // يوقف، ويعيد الثواني الباقية Insiyab.countdown('#timer', 'restart'); // من أوله Insiyab.countdown('#timer', 60); // من 60 ثانية Insiyab.countdown('#timer'); // الثواني الباقية، أو null ما دام لم يبدأ document.addEventListener('ins:countdown', (e) => { if (e.detail.state === 'end') release(e.detail.el); // أو 'warn' });

الخيارات

كل ما في العد التنازلي من كلاسات وسمات وأحداث، في صندوق يفتح بالنقر.
