العد التنازلي

ضع data-ins-countdown على .ins-countdown فيعد الوقت الباقي ثانية بعد ثانية. فإن كانت قيمتها رقمًا فهي ثوانٍ تبدأ من فتح الصفحة، وإلا فهي لحظة الانتهاء، مثل 2026-09-26T18:00:00+03:00. ويتلون العداد بالأصفر حين يبقى من الوقت data-ins-warn ثانية، أو دقيقة إن لم تذكرها، ثم بالأحمر عند الصفر، ويُطلق حدث ins:countdown في المرتين.

وإذا كان العد محور الصفحة فأعطه --lg.

document.addEventListener('ins:countdown', (e) => { if (e.detail.state === 'end') release(e.detail.el); // أو 'warn' }); Insiyab.countdown('#hold', 600); // من جديد

البدء والإيقاف عند الطلب

أضف data-ins-countdown-paused فيعرض العداد وقته كاملًا وينتظر، ثم تتحكم فيه بأزرار تشير إليه: data-ins-countdown-start يبدؤه، أو يكمله من حيث توقف، وdata-ins-countdown-stop يوقفه ويبقي الوقت الباقي ظاهرًا، وdata-ins-countdown-restart يعيده من أوله، وهو ما يحتاجه زر «أعد إرسال الرمز»:

ولا يتوقف العداد إذا انتقل صاحبه إلى نافذة أخرى، فإن أردت أن يتوقف ما دامت الصفحة في الخلفية ثم يكمل حين يعود إليها فأضف data-ins-countdown-pause-away، كمؤقت اختبار لا يُحسب فيه إلا الوقت الذي يقضيه أمامه.

والأوامر نفسها من JavaScript:

Insiyab.countdown('#cd-timer', 'start'); // يبدأ، أو يكمل من حيث توقف Insiyab.countdown('#cd-timer', 'stop'); // يوقف، ويعيد الثواني الباقية Insiyab.countdown('#cd-timer', 'restart'); // من أوله Insiyab.countdown('#cd-timer', 60); // من 60 ثانية Insiyab.countdown('#cd-timer'); // الثواني الباقية، أو null ما دام لم يبدأ

حالة الحفظ

يخبر .ins-save بمصير آخر تغيير: جارٍ حفظه، ثم حُفظ، أو تعذر حفظه. تضع الحالة في data-ins-state، فإن خلا منها حجز مكانه فارغًا، حتى إذا ظهر لم يقفز السطر.

الحفظ التلقائي

ضع data-ins-autosave على النموذج، فإذا مضت لحظة على آخر تغيير أظهر المؤشر «جارٍ الحفظ» وأطلق حدث ins:autosave يحمل بيانات النموذج. فإن أردت الحفظ على الخادم فاستدع preventDefault() على الحدث، ثم done(true) أو done(false) حين تنتهي. وإن لم تستدعها عدت المكتبة التغيير محفوظًا بما صنعه مستمعك، كأن يحفظه مسودة في المتصفح، وأعلن المؤشر ذلك في الحال.

document.addEventListener('ins:autosave', async (e) => { e.preventDefault(); const ok = await fetch('/draft', { method: 'POST', body: e.detail.data }).then((r) => r.ok); e.detail.done(ok); });
