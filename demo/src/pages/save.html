حالة الحفظ

يخبر .ins-save بمصير آخر تغيير: جارٍ حفظه، ثم حُفظ، أو تعذر حفظه. تضع الحالة في data-ins-state، أو تتركها للنموذج الذي يحفظ نفسه.

التحكم بـ JavaScript

تضع الحالة من جافاسكربت، أو تحفظ النموذج على الخادم بنفسك حين يطلق حدثه.

Insiyab.saveState('#status', 'saving'); // أو 'saved' أو 'error' أو 'idle' Insiyab.saveState('#status', 'saved', 'حُفظت المسودة'); document.addEventListener('ins:autosave', async (e) => { e.preventDefault(); const ok = await fetch('/draft', { method: 'POST', body: e.detail.data }).then((r) => r.ok); e.detail.done(ok); });

الخيارات

كل ما في حالة الحفظ من كلاسات وسمات وأحداث، في صندوق يفتح بالنقر.
