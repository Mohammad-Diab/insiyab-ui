جرب لونًا

كل زر هنا يستدعي Insiyab.brand(hex)، فتصطبغ الصفحة كلها بلونه، وتظهر تحتها القيم المشتقة منه.

62%

ضبط اللون

ضع السمة على <html>، أو استدع الدالة أثناء التشغيل، وكلاهما يشتق من اللون بقية ألوانه ويطبقها.

Insiyab.brand('#0F766E'); // يطبق Insiyab.brand(); // يعيد اللون الحالي

لون النص فوق لون الهوية

تحسب brand() تباين اللون مع الأبيض ومع الأسود القريب، ثم تكتب أوضحهما في --ins-on-primary ليكون لون النص فوقه. جرب الذهبي #C9A063 أعلاه وانظر إلى زر «حفظ».

من الخادم

إذا كان لكل عميل في تطبيقك لون هويته، فالطريق يسير: يعيد الخادم اللون مع بيانات الجلسة، وتطبقه الصفحة.

const res = await fetch('/api/session'); const { branding } = await res.json(); // { primary: '#1D4ED8', … } Insiyab.brand(branding.primary);

بلا جافاسكربت

إذا اكتفيت بملف الأنماط فاضبط اللون ومشتقاته بنفسك. وهذه قيم #0F766E في الوضع الفاتح، أما قيم الداكن فتأخذها من Insiyab.color.derive(hex, 'dark').

:root { --ins-primary: #0F766E; --ins-primary-rgb: 15, 118, 110; --ins-primary-dark: #0a504b; /* نهاية التدرج */ --ins-grad-rgb: 10, 80, 75; /* نهاية التدرج بصيغة RGB */ --ins-accent-rgb: 10, 80, 75; --ins-primary-darker: #073532; /* النص الملون المقروء */ --ins-on-primary: #ffffff; /* النص على السطح المملوء */ --ins-wash-1: #eef5f5; /* لونا خلفية الصفحة */ --ins-wash-2: #f0f5f4; }

النبرات

لكل نبرة ثلاثة متغيرات من صبغة واحدة: --ins-tone-* للنص، و-bg للخلفية، و-bd للحد.

ok · نجاح
warn · تحذير
bad · خطأ
info · معلومة
mute · خافت
brand · الهوية
 .my-badge { color: var(--ins-tone-warn); background: var(--ins-tone-warn-bg); border: 1px solid var(--ins-tone-warn-bd); }
