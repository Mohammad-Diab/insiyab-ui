جرّب لونًا

كلّ زرّ هنا يستدعي Insiyab.brand(hex) بقيمة واحدة، والمعاينة تحته — والصفحة كلّها — تتلوّن منها. أو اختر أيّ لون من المنتقي. يبقى اختيارك معك في صفحات التوثيق الأخرى.

القيم المشتقّة

التعيين

بسمة على <html>، أو بالدالّة وقت التشغيل. كلاهما يشتقّ المجموعة ويطبّقها.

Insiyab.brand('#0F766E'); // يطبّق Insiyab.brand(); // يعيد اللون الحالي

لون النصّ مقيس، لا مفترَض

كتابة الأبيض على الزرّ الرئيسي دائمًا خطأ حقيقي مع لون متوسّط الإضاءة: الأبيض على الذهبي #C9A063 تباينه قرابة ٢٫٤ إلى ١ — غير مقروء. لذلك تقيس brand() التباين مع الأبيض ومع الأسود القريب وتأخذ الأفضل، ثمّ تُبعد الطرف الثاني من التدرّج عن لون النصّ، فيحمل الزرّ كلّه نصّه بالبناء لا بالحظّ. جرّب الذهبي أعلاه وانظر إلى زرّ «حفظ».

من الخادم

نمط مجرَّب في تطبيق حقيقي: الخادم يعيد لون العميل مع جلسة الدخول، والصفحة تطبّقه. فالتطبيق الواحد يلبس هويّة كلّ عميل دون نسخة أنماط لكلّ منهم.

const res = await fetch('/api/session'); const { branding } = await res.json(); // { primary: '#1D4ED8', … } Insiyab.brand(branding.primary);

بلا جافاسكربت

إن استعملت ملفّ الأنماط وحده، فاضبط اللون ومشتقّاته بنفسك. هذه القيم هي ما تحسبه brand() للون #0F766E في الوضع الفاتح — وفي الداكن تتّجه الدرجة المقروءة نحو الأبيض، فاستعمل Insiyab.color.derive(hex, 'dark') لتحصل على قيمها.

:root { --ins-primary: #0F766E; --ins-primary-rgb: 15, 118, 110; --ins-primary-dark: #0a504b; /* نهاية التدرّج */ --ins-grad-rgb: 10, 80, 75; /* الثلاثيّة نفسها لنهاية التدرّج */ --ins-accent-rgb: 10, 80, 75; --ins-primary-darker: #073532; /* النصّ الملوّن المقروء */ --ins-on-primary: #ffffff; /* النصّ على السطح المملوء */ --ins-wash-1: #eef5f5; /* غَسلتا خلفية الصفحة */ --ins-wash-2: #f0f5f4; }

الثلاثيّة الدلالية

كلّ حالة ثلاثة ألوان من صبغة واحدة: نصّ داكن مشبع، وخلفية بنسبة ١٠–١٢٪ منها، وحدّ بنسبة ١٨–٢٢٪. لهذا تُقرأ الشارة والتنبيه والزجاج عائلةً واحدة لا ثلاثًا.
