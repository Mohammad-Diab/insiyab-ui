التثبيت

إضافة مستقلة عن المكتبة: ملف أنماط وملف سكربت تضعهما بعد ملفاتها.

مركز الإشعارات

ضع data-ins-notify على قائمة منسدلة زرها جرس، فيعد السكربت الصفوف التي عليها data-ins-unread ويكتب عددها على زاوية الجرس، ويصير الصف مقروءًا حين يُنقر. وتجد الخيارات كلها بشرحها في آخر الصفحة.

متى تستعمل مركز الإشعارات

  • لما يحدث والمستخدم بعيد عنه، ويبقى حتى يراه: اكتمل عمل طويل، أو وصل تعليق.
  • أما تأكيد ما فعله المستخدم للتو فمكانه الرسالة العابرة، تظهر ثم تغيب.

التحكم بـ JavaScript

إذا وصل إشعار من الخادم فأضف صفه إلى القائمة، فيعده الجرس ويهتز مرة واحدة.

Insiyab.notify('#inbox'); // عدد غير المقروءة Insiyab.notify('#inbox', item); // تعليم صف مقروءًا، بهدوء Insiyab.notify('#inbox', 'all'); // تعليمها كلها مقروءة document.addEventListener('ins:notify', (e) => { console.log(e.detail.item, e.detail.all); // حين يعلمها المستخدم مقروءة });
