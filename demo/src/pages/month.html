التحميل

شهر بمواعيده

.ins-month مع data-ins-month="2026-09"، وفيه قائمة .ins-month-events هي محتواه: كلّ عنصر موعد في يوم (data-date، واختياريًا data-time وdata-tone). يرسم منها الشهر جدول أسابيع يبدأ باليوم الذي تبدأ به لغة الصفحة الأسبوع، واليوم الحالي معلَّم، وفي اليوم ثلاثة مواعيد و«+2» للباقي، والرابط يبقى رابطًا. وعلى الهاتف تصير المواعيد نقاطًا.

الأحداث

التنقّل بين الأشهر يُطلق ins:month بالشهر الجديد، فتضع الصفحة مواعيده في القائمة وتستدعي Insiyab.month(el)، أو تسلّمها مباشرة. والنقر على يوم خارج مواعيده يُطلق ins:month-day بتاريخه.

document.addEventListener('ins:month', async (e) => { const events = await load(e.detail.month); // [{ date, title, href, tone, time }] Insiyab.month(e.detail.el, { events }); }); document.addEventListener('ins:month-day', (e) => openNew(e.detail.date));
